Chatbox Lite 首个聊天精简版，尽量保留原版 Chatbox 的界面和聊天操作习惯。

### 下载与使用

- `Chatbox-Lite-0.1.0-macOS-arm64.zip`：适用于 Apple Silicon Mac。
- 解压后把 `Chatbox Lite.app` 拖入“应用程序”文件夹，再打开使用。
- 应用使用本地临时签名，未经过 Apple 公证。如果 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开。
- `SHA256SUMS.txt` 提供安装包校验值。

### 聊天精简

保留多会话、流式回复、Markdown、代码和公式、消息编辑与重试、会话分支、搜索、上下文压缩、图片输入、本地文件解析、导入导出和主题设置。

移除 MCP、知识库、Skills、Agent 与工具执行、记忆、Chatbox 账户与订阅、云解析、生成图片、“我的搭档”及网页发布；关闭原版遥测和自动更新。

### 自定义 Gemini 供应商

在“设置 → 模型提供方 → 添加 → 添加自定义提供方”选择“使用 AGIHub Gemini 预设”，填入自己的 API Key 即可。预设模型为 `gemini-4-argon`，使用 Bearer 鉴权和 `generateContent` 接口。

支持 Google API Key / Bearer 鉴权、请求体 `model` 字段和流式开关；输入框可选择默认、低、中、高推理强度。Gemini 3 及更新命名模型使用 `thinkingLevel`，Gemini 2.5 使用 `thinkingBudget`，自定义模型别名可手动指定模式。

### 数据与验证

Lite 使用独立的数据目录。旧版聊天可以导出后导入；已移除功能的旧配置不会重新启用服务，历史工具记录仅供查看。

本地完整测试 6,795 项通过、14 项跳过。已验证 macOS 桌面启动、Electron HTTP 通道、文本与图片附件、PDF 解析、Markdown 显示、自动命名、记录恢复和多轮对话。AGIHub 协议使用模拟服务验证，未用真实 API Key 调用线上模型。
