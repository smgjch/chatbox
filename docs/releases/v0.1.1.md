为原生 Gemini 聊天增加“思考摘要”面板，并清楚区分服务端未提供摘要和未提供推理用量。

### 更新内容

- Gemini 返回原生摘要时，可在回复上方展开、收起和复制。
- 未返回摘要时显示“服务端未提供摘要”；返回推理 token 时显示真实数量，未返回时显示“未提供推理用量”。
- 修正 SDK 将缺失的推理用量补为 0 的行为。服务端明确报告的 0 与未知用量分别展示。
- 默认推理强度也会请求原生摘要，但不指定 thinkingLevel 或 thinkingBudget；显式关闭推理时仍保持关闭。
- 支持流式和非流式网关，摘要和用量随聊天记录保存。不会额外调用模型，也不会根据答案生成或猜测思考摘要。

网关必须返回 Gemini 的 `thought: true` 文本才能展示原生摘要。仅开启推理强度无法保证服务端公开摘要。

### macOS 下载与更新

下载 `Chatbox-Lite-0.1.1-macOS-arm64.zip`，适用于 Apple Silicon Mac。退出旧版应用，解压后将 `Chatbox Lite.app` 拖入“应用程序”替换旧版，再打开。保留原有 Lite 设置和聊天记录。

应用使用本地临时签名，未经 Apple 公证。如果 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中允许打开。`SHA256SUMS.txt` 提供安装包校验值。

应用与工作区 TypeScript 检查通过；本地回归共 6,809 项通过、14 项跳过。桌面实测通过：摘要展开与记录恢复、缺失摘要提示、缺失用量提示，以及每条回答仅一次聊天调用。协议和显示使用模拟 Gemini 服务验证，未使用真实 API Key 调用 AGIHub。沿用 GPL-3.0 许可证。
